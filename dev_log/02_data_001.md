# Unit 2: Data - Subunit: API Service Function

## Objective
Create basic API service function to fetch weather data from the CGI endpoint with fundamental error handling.

## Implementation
- Create `src/api/weather.js` with fetch function
- Use environment variable `VITE_API_BASE_URL` for configurable backend endpoint
- Handle HTTP requests to `${VITE_API_BASE_URL}/cgi-bin/weather.cgi?city=Wellington`
- Create `.env` file with default localhost:8000 configuration
- Implement basic error handling for network failures, timeouts, and parse errors
- Set 5-second timeout for API calls
- Return raw API response for testing and validation
- Handle XML parsing from CGI response

## AI Interactions

- Implemented AbortController for 5-second timeout handling

- Created error categorization: timeout, network, not_found, parse_error
- Added test component in App.jsx to verify API service functionality
